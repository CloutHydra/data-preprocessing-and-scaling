# Data Preprocessing and Scaling Coursework

Python coursework demonstrating common data-preprocessing techniques and how transformations affect numerical data.

## Projects

### Wine Dataset: Normalization, Scaling, and Encoding
Uses scikit-learn's Wine dataset to demonstrate:
- one-hot encoding of categorical targets;
- Min-Max normalization;
- standard scaling;
- reciprocal transformation;
- equilateral class encoding; and
- visual comparison of feature distributions before and after transformations.

Run:
```bash
python wine_normalization_scaling.py
```

### Simple Scaling Visualization
Generates a two-dimensional synthetic dataset, then compares:
- the original data;
- zero-centered data; and
- Min-Max normalized data.

Run:
```bash
python simple_scaling_visualization.py
```

## Skills Demonstrated
Python, NumPy, pandas, Matplotlib, scikit-learn, preprocessing, feature scaling, encoding, data visualization.

## Context
These programs were completed as part of university coursework and are published here as examples of Python/data-analysis practice.
